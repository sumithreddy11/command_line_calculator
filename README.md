# Command Line Utility Tool (C++)

A menu-driven command-line application written in C++ that provides multiple utility functions with  input validation and error handling.

## Features

### 1. Basic Calculator
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero protection

### 2. Temperature Converter
- Celsius ↔ Fahrenheit
- Celsius ↔ Kelvin
- Fahrenheit ↔ Kelvin
- Absolute-zero validation

### 3. Word and Character Counter
- Word count
- Character count (with spaces)
- Character count (without spaces)
- Line count
- Average words per line
- Average characters per word

### 4. Prime Number Checker
- Prime number detection
- Composite number identification
- Prime factorization
- Next prime number finder
- Prime gap calculation

## Technologies Used

- C++
- Standard Template Library (STL)
- Object-Oriented Programming concepts
- Input validation techniques
- Modular function design
